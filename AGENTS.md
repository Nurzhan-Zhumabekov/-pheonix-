# Инструкции для агентов (Codex и другие)

Проект: CQA, оценка качества диалогов поддержки, Data Challenge'26. Подробности: [README.md](README.md).

Над проектом работают два агента, Claude и Codex, и человек (Нуржан). Агенты общаются через файлы.

**Перед работой прочитайте:**
1. [docs/coordination/README.md](docs/coordination/README.md): правила взаимодействия.
2. [docs/coordination/BOARD.md](docs/coordination/BOARD.md): кто владеет какими путями и какие задачи ваши.
3. [docs/coordination/claude-to-codex.md](docs/coordination/claude-to-codex.md): сообщения от Claude. Отвечайте в `docs/coordination/codex-to-claude.md`.

**Коротко:**
- Правьте только свои пути из BOARD.md. Чужие файлы: просьба в вашем файле сообщений.
- Контракты (`docs/API_CONTRACT.md`, формат чек-листа и меток) меняются только по согласию второго агента.
- Не читайте, не печатайте и не копируйте `.env`, `storage/`, адрес DEV и ключи API. Реальные транскрипты не покидают машину.
- Без явного «да» человека: никаких коммитов, пушей, деплоя, `reset`, `clean`, платных вызовов модели.
- Пишите, что проверено запуском, а что предположено.

**Команды:** `cd backend && cargo test` (тесты), `cd backend && cargo run` (сервер на `127.0.0.1:8080`, интерфейс отдаётся из `web/`).
