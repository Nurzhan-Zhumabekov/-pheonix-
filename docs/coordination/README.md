# Как работают Claude и Codex вместе

Проект: CQA для Data Challenge'26 (см. [../../README.md](../../README.md)). Дедлайны: контрольные диалоги открываются около 11:00 вс 8 нояб, стоп-код в 12:00, питч в 13:00.

## Участники

- **Claude** (Claude Code, рабочая папка `C:\Users\admin\Desktop\Rust`).
- **Codex** (OpenAI Codex).
- **Нуржан** (человек): арбитр и посредник. Агенты не могут вызвать друг друга напрямую, поэтому общаются через файлы в этой папке. Нуржан сообщает агенту «посмотри, что написал второй».
- Напарница Нуржана (фуллстек) работает параллельно, детали по её задачам в [BOARD.md](BOARD.md).

## Файлы

| Файл | Кто пишет | Что это |
|---|---|---|
| [BOARD.md](BOARD.md) | оба, каждый свои строки | владельцы путей, задачи, статусы, открытые вопросы |
| [claude-to-codex.md](claude-to-codex.md) | только Claude | сообщения Claude для Codex |
| [codex-to-claude.md](codex-to-claude.md) | только Codex | сообщения Codex для Claude |

Один файл сообщений: один автор. Так записи не затирают друг друга.

## Правила

1. **В начале каждой сессии** прочитайте BOARD.md и файл сообщений от второго агента. Отвечайте на всё, что помечено `Нужно:`.
2. **Формат записи** (новые внизу): `## ГГГГ-ММ-ДД ЧЧ:ММ · тема`, затем что сделано, что нужно от второго, что заблокировано, пути к файлам. Короткие записи, без вставок кода больше 20 строк (ссылайтесь на файл).
3. **Владение путями.** Не правьте чужие пути из BOARD.md. Нужна правка в чужом файле: напишите `Нужно:` в своём файле и ждите ответа. Конфликт или срочность: спросите Нуржана.
4. **Контракты** (`docs/API_CONTRACT.md`, формат `config/checklist.default.json`, формат меток из BOARD.md): перед изменением сообщите второму агенту, что меняется и зачем, и дождитесь согласия. Обратно несовместимые правки без согласия запрещены.
5. **Секреты и данные.** Не читайте, не печатайте и не копируйте `.env`, `storage/`, адрес DEV и ключи API. Нужна проверка конфигурации: смотрите только имена и длины, как это делал Claude. Реальные транскрипты звонков не покидают локальную машину и не попадают ни в репозиторий, ни в сообщения агентов. Не читайте чужие проекты на диске без прямого указания Нуржана.
6. **Git.** Без явного «да» от Нуржана: никаких коммитов, пушей, деплоя, смены веток, `reset`, `clean` и удаления чужих файлов.
7. **Статусы задач:** TODO, DOING, REVIEW, DONE, BLOCKED. Меняйте только свои строки.
8. **Расходы.** Запросы к платным API (оценка диалогов моделью) только по согласованию с Нуржаном, с оценкой стоимости заранее.
9. **Честные отчёты.** Пишите, что проверено запуском, а что только прочитано или предположено. Не заявляйте «готово» без проверки.
