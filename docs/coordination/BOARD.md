## Контракты

- API: [../API_CONTRACT.md](../API_CONTRACT.md). Сервер: `cd backend && cargo run`, адрес `http://127.0.0.1:8080`, ответы с `"mock": true`, если модель не настроена.
- Формат меток (**утверждён Claude и Codex, 2026-11-07 22:55**): `storage/labels.json`, объект `conversation_id → {"checklist_version": N, "answers": {"<criterion_id>": "yes" | "no" | "na" | число}, "gross": null | true | false, "labeler": "имя", "note": "текст", "updated_at": "…"}`. Нет ключа в `answers` = не размечено, `"na"` = явный N/A, числа = сырые ступени шкалы, `gross: null` = не размечено. Отчёт сравнивает только размеченные поля и только если версия метки совпадает с версией оценки. API (реализует Claude, задача C1): `GET /api/labels`, `GET /api/labels/{conversation_id}`, `PUT /api/labels/{conversation_id}` (полная замена записи, проверка id критериев и допустимости ответов по версии метки).
